WHAT IT TEACHES:
================================================================================

Security Concepts:

  ✅ TCB Theory
     - Correctness (agents are probabilistic, not deterministic)
     - Complete Mediation (prompt injection defeats agent logic)
     - Tamper-proof (agents can be jailbroken/manipulated)

  ✅ Control Plane Architecture
     - Permission enforcement (system-level, not agent-managed)
     - Tool sandboxing (OS-level isolation)
     - Audit logging (tamper-proof records)
     - Rate limiting (infrastructure-level abuse prevention)
     - Input validation (pre-execution checking)
     - Anomaly detection (real-time monitoring)

  ✅ Real Attack Scenarios
     - Prompt injection success/failure
     - Over-privilege exploitation
     - File system access breaches
     - Database compromise
     - Email/API abuse

  ✅ Defense Strategies
     - Layered controls (defense in depth)
     - Microsegmentation (fine-grained permissions)
     - Real-time alerting (catch breaches immediately)
     - Approval workflows (for sensitive operations)
